# GameVault Inventory: [Live Preview](https://inventory-app-q56f.onrender.com "Go to GameVault")

A full-stack game inventory management application built with Node.js, Express, PostgreSQL, EJS, and Tailwind CSS.
- Submitted for The Odin Project

## Features

- Browse all games in the inventory
- Filter games by category
- View individual game details
- Add and edit games
- Add and edit categories
- Admin-protected editing and deletion
- Light and dark theme switcher
- Responsive game-store-inspired interface

## Tech Stack

- Node.js
- Express
- PostgreSQL
- EJS
- Tailwind CSS
- Render deployment
